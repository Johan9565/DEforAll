# Plan: Rediseño de Ilustraciones con librerías reales

## Objetivo

Reemplazar los 5 generadores SVG a mano (Formas, Iconos, Modelos 3D, SmartArt, Gráfico) por **librerías reales**, priorizando:

1. **Calidad del resultado insertado** (SVG vectoriales nítidos, look profesional)
2. **Catálogo mucho mayor**
3. **Librerías de verdad**, no strings SVG escritos a mano

## Stack elegido (multi-librería, MIT/Apache/ISC)

| Categoría | Paquete | Licencia | Catálogo | Export a `setImage` |
|-----------|---------|----------|----------|---------------------|
| **Gráficos** | `echarts` (tree-shaken + SVGRenderer) | Apache-2.0 | 20+ tipos | `serialize(svg)` → data URI |
| **Iconos** | `@iconify/utils` + `@iconify-json/lucide` + `@iconify-json/tabler` | MIT/ISC | ~7.500 iconos | `iconToSVG()` → data URI |
| **Formas** | Pack SVG estático curado (40–60) + `@svgdotjs/svg.js` | MIT | 40–60+ | `?raw` / `draw.svg()` → data URI |
| **Diagramas** | `mermaid` (dynamic import) | MIT | ~20 tipos | `render().svg` → data URI |
| **Ilustraciones** | Pack estático (unDraw-style, 30–50 SVGs) | gratuito | 30–50 | `?raw` → data URI |

**No usar:** `elkjs` (EPL/GPL), `@iconify/json` completo (502 MB), `three.js` (pesado, bajo ROI), `@heroicons/react` (peer React).

### 3. `src/utils/chartGenerator.ts` — reescrito con ECharts

**Eliminar** todo el motor SVG a mano (~656 líneas).

**Nuevo flujo:**
- Modal con: selector de tipo (con miniaturas reales), editor de datos, título, paleta, tamaño
- Tipos iniciales (12+): barras, barras horizontales, líneas, área, pastel, dona, dispersión, radar, embudo, medidor, treemap, burbujas
- Render offscreen con `SVGRenderer` → `XMLSerializer` → `svgToDataUri`
- Preview escalado (`max-width/height:100%`), **nunca recortado**

```ts
import * as echarts from 'echarts/core';
import { BarChart, LineChart, PieChart, ScatterChart, RadarChart, FunnelChart, GaugeChart, TreemapChart } from 'echarts/charts';
import { GridComponent, TooltipComponent, LegendComponent, TitleComponent, DatasetComponent } from 'echarts/components';
import { SVGRenderer } from 'echarts/renderers';

echarts.use([BarChart, LineChart, PieChart, ScatterChart, RadarChart, FunnelChart, GaugeChart, TreemapChart,
  GridComponent, TooltipComponent, LegendComponent, TitleComponent, DatasetComponent, SVGRenderer]);

export function echartsToSvgDataUri(option: any, w = 800, h = 500): string {
  const host = document.createElement('div');
  host.style.cssText = `width:${w}px;height:${h}px;position:absolute;left:-9999px`;
  document.body.appendChild(host);
  const chart = echarts.init(host, undefined, { renderer: 'svg', width: w, height: h });
  chart.setOption(option);
  const svg = host.querySelector('svg')!;
  const markup = new XMLSerializer().serializeToString(svg);
  chart.dispose(); host.remove();
  return svgToDataUri(markup);
}
```

**Bugs corregidos de paso:** valores aleatorios al añadir fila (ahora 0 o copia del anterior), `showLegend` muerto (checkbox real), preview recortado.

### 4. `src/utils/iconPickerModal.ts` — reescrito con Iconify

**Eliminar** la lista hardcodeada de 32 iconos.

**Nuevo flujo:**
- Pestañas por set: Lucide | Tabler
- Búsqueda instantánea sobre nombres del set (≈7.500 iconos)
- Grid virtualizado o paginado (máx. ~200 en DOM)
- Color: picker nativo `<input type="color">` + swatches
- Tamaños: 16 / 24 / 32 / 48 / 64 / 96 / 128
- Sin fondo / círculo / cuadrado (se mantiene)

```ts
import { icons as lucideIcons } from '@iconify-json/lucide';
import { getIconData, iconToSVG } from '@iconify/utils';

function iconToSvgDataUri(set: any, name: string, opts: { size?: number; color?: string } = {}): string {
  const { size = 32, color = '#111' } = opts;
  const icon = getIconData(set, name);
  if (!icon) return '';
  const { attributes, body } = iconToSVG(icon, { width: size, height: size });
  const attrs = Object.entries(attributes).map(([k, v]) => `${k}="${String(v)}"`).join(' ');
  return svgToDataUri(`<svg xmlns="http://www.w3.org/2000/svg" ${attrs} color="${color}">${body}</svg>`);
}
```

**Bug corregido:** check invisible en swatches claros.

```ts
let mermaidPromise: Promise<any> | null = null;
async function getMermaid() {
  if (!mermaidPromise) {
    mermaidPromise = import('mermaid').then((m) => {
      m.default.initialize({ startOnLoad: false, theme: 'neutral', securityLevel: 'strict', fontFamily: 'Inter, system-ui, sans-serif' });
      return m.default;
    });
  }
  return mermaidPromise;
}
export async function mermaidToSvgDataUri(code: string): Promise<string> {
  const mermaid = await getMermaid();
  const { svg } = await mermaid.render('mmd-' + crypto.randomUUID(), code);
  return svgToDataUri(svg);
}
```

## Riesgos y tradeoffs

| Riesgo | Mitigación |
|--------|------------|
| Bundle size (echarts + iconify JSON + mermaid) | Tree-shake echarts; dynamic `import()` mermaid y sets de iconos; assets SVG estáticos no pesan runtime |
| Mermaid lento en primer render | Dynamic import + spinner; cachear instancia |
| Iconify JSON grande en bundle | Importar solo lucide+tabler; opcional: lazy por pestaña |
| SVG text sin embed de fuentes | Aceptar system-font fallback; para títulos críticos convertir a paths |
| unDraw licensing | unDraw es licencia abierta libre para uso comercial sin atribución; verificar cada pack alternativo |
| Cambio de API de `openXxxModal` | Mantener firma `(editor) => void` en todos los exports |
